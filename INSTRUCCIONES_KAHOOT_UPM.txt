KAHOOT INGLÉS UPM — ANA VS MPAZ

1. Sube kahoot_ingles_upm.html a la raíz del repositorio UPM.
2. Abre https://anabchic87-blip.github.io/UPM/kahoot_ingles_upm.html
3. En Firebase Console, selecciona el proyecto que usaréis. En Authentication > Sign-in method, habilita Anonymous (Anónimo).
4. Crea una Realtime Database (no Firestore). En sus reglas, para una prueba privada, puedes usar las reglas de abajo. IMPORTANTE: permiten a cualquier usuario autenticado anónimamente leer/escribir las salas; no son adecuadas para datos privados ni para una aplicación pública con garantías antitrampas. Usa una base separada para el juego y no las apliques a una base con otros datos.
5. En Configuración del proyecto > Tus aplicaciones > Web > Configuración, copia el objeto firebaseConfig completo y pégalo en la primera pantalla. Asegúrate de que incluye databaseURL. No necesitas pegarlo dentro del código HTML.
6. Las dos abrís la misma URL en vuestros móviles, configuráis Firebase una vez, escribís vuestro nombre; una crea sala y la otra se une con el código de seis cifras.
7. Si usáis GitHub Pages, añade el dominio anabchic87-blip.github.io a Authentication > Settings > Authorized domains si fuera necesario.
8. Para añadir acceso desde ingles.html, inserta un enlace a kahoot_ingles_upm.html.

REGLAS DE PRUEBA PARA UNA BASE DEDICADA EXCLUSIVAMENTE A ESTE JUEGO:
{
  "rules": {
    "upmEnglishRooms": {
      "$room": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}
