Conectar la partida

La primera vez, pega la configuración web de Firebase de vuestro proyecto. Se guarda únicamente en este navegador.

¿Dónde está la configuración?

Firebase Console → Configuración del proyecto → Tus aplicaciones → aplicación web → Configuración. Activa también Authentication → método Anónimo y Realtime Database. Las reglas necesarias están en las instrucciones adjuntas.

Entrar al juego

Sala

Comparte el código con la otra jugadora.

⏱ 15 s

Una respuesta por persona. 15 segundos por pregunta. Puntos por acertar y por rapidez. La persona anfitriona avanza al siguiente turno cuando ambas han respondido o se acaba el tiempo.
